# 단단이 V0.5.1 — 아침의 시작
- V0.4.1 디자인 개선판을 복사해 별도 폴더로 개발했습니다.
- 사진 11장과 사진형 3열 카드를 그대로 보존했습니다.
- 아침 창작 문장 6편(해설, 사상적 배경, 실천)을 추가하고 날짜별로 한 편씩 보여줍니다.
- 오늘의 문장 해설은 기본 펼침 상태입니다.
- 사이드바 '나만의 하루 창조하기'는 기본 꺼짐이며 선택 시 간단한 하루 계획을 보여줍니다.
- 알림 설정은 여전히 선호 저장 시제품이며 실제 푸시를 보내지 않습니다.
- 사용자 기록은 실행 폴더의 로컬 JSON 파일에 저장되며 Colab 세션 초기화 시 사라질 수 있습니다.
- 개인 Colab 테스트 전용이며 공개 다중 사용자 서비스에 적합하지 않습니다.
